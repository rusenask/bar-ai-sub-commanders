# Counter matrix specs (scenario battle)

One category against another at about 2000 metal a side (raiders, assault, skirmishers, heavy, artillery;
Legion has no T1 artillery), within each faction, the enemy attacking: what beats what, measured, to check
the production counter matrix (sc_doctrine.lua D.response) and find the kinds our micro handles badly.
`go run ./cmd/gamereport -battles <batch>` gives efficiency per spec; `scripts/counter_matrix.py` the matrix.
